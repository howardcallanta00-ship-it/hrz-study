## Answer Key

1. **A.** A piecewise function uses multiple rules on specified x-intervals. B describes nominal data; C describes trigonometric ratios generally; D concerns data representation. *(Piecewise Function, p. 1)*
2. **B.** A breakpoint is where one subdomain ends and the next begins. A is not the definition; C is ordinal; D is ratio. *(Piecewise Function, p. 1)*
3. **C.** The rules change at x = 0. -1 and 1 are ordinary inputs; the displayed function clearly has a breakpoint. *(Piecewise Function and displayed function, p. 1)*
4. **D.** Because -3 < 0, the x - 1 rule applies. A chooses the wrong rule; B and C use the wrong condition. *(Displayed function, p. 1)*
5. **A.** Substitution gives -3 - 1 = -4. B omits the subtraction; C adds 1; D changes the sign without following the rule. *(Displayed function, p. 1)*
6. **B.** Since 0 ≥ 0, use f(x) = x, so f(0) = 0. A incorrectly uses x - 1; C adds 1; D ignores the inclusive ≥ sign. *(Displayed function, p. 1)*
7. **C.** The reviewer defines data broadly as collected numbers, facts, or details used for learning and decisions. A and B are too narrow; D describes ordinal data. *(Types of Data, p. 1)*
8. **A.** Representations help people understand information quickly and easily. B-D claim effects not stated in the reviewer. *(Types of Data, p. 1)*
9. **D.** Quantitative data are numerical, countable or measurable, and support operations. A-C describe qualitative data. *(Types of Data, p. 1)*
10. **B.** Qualitative data represent attributes or labels grouped into categories. A, C, and D describe numerical properties. *(Types of Data, p. 1)*
11. **A.** Preferred fruit is an attribute/category. B is numerical; C and D are numerical measurement levels. *(Types of Data; Nominal examples, p. 1)*
12. **C.** Number of siblings is a count, hence quantitative. A, B, and D incorrectly treat it only as a label/category. *(Quantitative Data; Ratio examples, pp. 1-2)*
13. **B.** Nominal data are names or categories without order. A is interval; C is ordinal; D is ratio. *(Level of Measurement, p. 1)*
14. **D.** Internet-connection type is a label with no ranking. A and B are ordinal; C is interval. *(Nominal examples, p. 1)*
15. **A.** The ID number labels the student; it is not used as a measurable amount or rank. B-D assign meanings the reviewer does not give it. *(Nominal examples, p. 1)*
16. **A.** Ordinal values can be ordered, but rank differences are not measurable. B is nominal; C is interval; D is ratio. *(Ordinal, pp. 1-2)*
17. **C.** Satisfaction categories are ordered. A is nominal; B is interval; D is ratio. *(Ordinal examples, p. 1)*
18. **B.** Meaningful order distinguishes ordinal from nominal categories. A, C, and D concern numerical operations or the higher numerical levels. *(Nominal and Ordinal, pp. 1-2)*
19. **D.** Interval data have equal meaningful differences but no true zero. A is ordinal; B is nominal; C is ratio. *(Interval, p. 2)*
20. **A.** Calendar years are an interval example. B is ratio; C is ordinal; D is nominal. *(Interval examples, p. 2)*
21. **C.** The reviewer explicitly says 0°C does not mean no temperature. A concerns ranking; B describes true zero; D is false because interval differences are meaningful. *(Interval, p. 2)*
22. **B.** Ratio adds a true/absolute zero to the equal-difference property. A can apply beyond ratio; C is qualitative; D is ordinal. *(Ratio, p. 2)*
23. **D.** Time spent studying has a true zero. A is interval; B is ordinal; C is nominal. *(Ratio examples, p. 2)*
24. **A.** “Twice as much” comparisons make sense with ratio data. B-D lack the stated true-zero basis for such comparisons. *(Ratio recognition, p. 2)*
25. **C.** All three match reviewer examples. A misclassifies every item; B misclassifies all three; D also misclassifies all three. *(Levels of Measurement, pp. 1-2)*
26. **B.** Meaningful rank without measurable rank gaps is ordinal. A lacks order; C and D have measurable differences. *(Ordinal, pp. 1-2)*
27. **D.** Equal differences plus a true zero define ratio data. A and B are categorical; C lacks a true zero. *(Ratio, p. 2)*
28. **A.** sin(θ) = opposite/hypotenuse. B is adjacent/hypotenuse; C is opposite/adjacent; D is adjacent/opposite. *(Trigonometric-ratio diagram, p. 2)*
29. **C.** cos(θ) = adjacent/hypotenuse. A is hypotenuse/adjacent; B is opposite/adjacent; D is hypotenuse/opposite. *(Trigonometric-ratio diagram, p. 2)*
30. **B.** tan(θ) = opposite/adjacent. A reverses it; C and D use the hypotenuse. *(Trigonometric-ratio diagram, p. 2)*
31. **A.** cot(θ) = adjacent/opposite. B uses hypotenuse/opposite; C uses adjacent/hypotenuse; D reverses the requested ratio. *(Trigonometric-ratio diagram, p. 2)*
32. **D.** sec(θ) = hypotenuse/adjacent. A is opposite/hypotenuse; B is adjacent/opposite; C is hypotenuse/opposite. *(Trigonometric-ratio diagram, p. 2)*
33. **B.** csc(θ) = hypotenuse/opposite. A is adjacent/hypotenuse; C is hypotenuse/adjacent; D is opposite/adjacent. *(Trigonometric-ratio diagram, p. 2)*
34. **C.** Sine is opposite/hypotenuse and cosecant reverses it. The other pairings do not reverse the same two sides. *(Trigonometric-ratio diagram, p. 2)*
35. **False.** Corrected: x = 0 uses the **x rule** because its condition is x ≥ 0. *(Displayed function, p. 1)*
